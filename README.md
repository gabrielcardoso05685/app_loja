# App Loja Simples

Projeto básico em Flask, sem banco de dados.

## Telas
- Login
- Dashboard com produtos simulados
- Cadastro de usuário

## Login
- E-mail: admin@loja.com
- Senha: 123

## Executar no CMD

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Depois acesse `http://127.0.0.1:5000`.
